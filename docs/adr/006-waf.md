# Limites de taxa e proteção de borda sem API Gateway (sec. 5.1, 9).

Status: Accepted (2026-11-10)

## Requisito
WAF v2 (CLOUDFRONT) com IP reputation, Common, KnownBadInputs, SQLi, rate limit global (2000/5 min/IP) e OTP (50/5 min/IP). Bot Control adiado para a S8 (custo).

## Decisão
~US$ 10–15 + pedidos.

## Custo fixo mensal estimado (us-east-1, a validar na fatura)
Rate limit só na aplicação.

## Alternativa mais simples
Regras gerenciadas podem dar falsos positivos; começar em contagem se necessário.
